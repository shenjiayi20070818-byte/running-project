# 02 轨迹模拟

本轮成功路径是配置点组成的闭合折线，代码在[mumu_route.position](../../code/run-sim/mumu_route.py#L41)。点来自本机当前地图复核；公开配置已全部置空，不提供校园、经纬度或实际轨迹。

算法把输入经纬度换成本地区域平面坐标，近似比例为纬向111320米/度，经向再乘中心纬度的cos。计算每段长度，把累计路程对整圈长度取模，找到所在段，再按比例线性插值回经纬度。该近似只用于局部测试；投影误差和转角弦长缩短应独立测量。

默认约每秒发送一次位置。先持共享锁并验证起点，写一次首点后进入`armed`；人工确认APP准备和步频accepted后才发`start`文件。`pause`文件存在时不写位置、不增加模拟时间；恢复从最后发出的点继续。`stop`只停止后续位置，不重置到起点。

成功会话采用速度约3.3333m/s，输入路线预算3100米。JSONL会记录计划有效时间、指令累计距离、坐标、分段、CLI耗时和响应。原始JSONL只在本机保存，未上传。停止/暂停、重连修复和后续监测代码包含在快照中；未因此宣称所有故障场景实机通过。
